# Technical Learning Journey 

This repository serves as an engineering workspace dedicated to documenting my learning progress, academic laboratory practices, and hands-on experiments at the intersection of mechatronics, software, and systems security.

## 📁 Repository Structure

### 1. `/Arduino` (Microcontroller & Hardware Control)
- **Focus:** Firmware development, peripheral interfacing, and cyber-physical automation.
- **Core Concepts:** Real-time sensor data processing, motor driver integration (H-Bridge/PWM), signal stabilization algorithms (such as software-defined deadzones).

### 2. `/C-Programming` (Software Fundamentals)
- **Focus:** Low-level programming architecture and data manipulation using the C language.
- **Core Concepts:** Memory management, pointer operations, custom structure designs (`struct`), functional programming, and algorithmic efficiency.

### 3. `/Secure-Coding` (Defensive Software Design)
- **Focus:** Identifying and mitigating software-level vulnerabilities during development.
- **Core Concepts:** Input validation methods, boundary checking implementations (preventing Buffer Overflow), and memory safety practices.
